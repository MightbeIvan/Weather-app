# API WEATHER PROGRAM

Finds the weather of any location with the help of APIs.

## Description
This program gets the current weather of any location using the OpenWeatherMap API and displays it in the command line. Users can view temperature, humidity, wind speed, weather conditions, and the "feels like" temperature. The program also converts Celsius temperatures to Fahrenheit and allows multiple searches without restarting the application.

## Executing the Program

In your IDE, make sure you are in the project folder in the terminal and type:

```sh
python weatherapp.py
```

## Features

* Search weather by city name
* View current temperature in Celsius
* Convert temperature to Fahrenheit
* View humidity levels
* View wind speed
* View weather description
* View "Feels Like" temperature
* Loading animation
* Error handling for invalid locations
* Run multiple searches without restarting
